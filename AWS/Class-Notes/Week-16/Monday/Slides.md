Slide 4 — Proposed Solution Overview

Proposed Solution Overview

Each testing site connects to a centralized cloud network hub

Enterprise-grade Cisco router at each site

Business-class internet + encrypted VPN tunnels

Dynamic routing (BGP) for resilience and controlled route exchange

Central hub governs connectivity, policy, and visibility

Operational Model

Traffic flows only between authorized systems and locations
