10-Day Plan

Day 1 — Linux + Docker + AWS Setup

Create EC2 instances, install Docker/containerd, and connect using VS Code Remote SSH.

Day 2 — Install Kubernetes Cluster

Install kubeadm, kubelet, kubectl, initialize the control plane, install Calico, and join workers.

Day 3 — Pods + YAML

Create Pods, export YAML, practice labels, annotations, commands, and environment variables.

Day 4 — Deployments + Scaling

Create Deployments, scale replicas, test rolling updates, and practice rollbacks.

Day 5 — Services + Networking

Create ClusterIP and NodePort services. Troubleshoot labels, selectors, and endpoints.

Day 6 — Ingress + Helm

Install Helm, deploy NGINX Ingress Controller, and test hostname/path routing.

Day 7 — Storage

Create PersistentVolumes, PersistentVolumeClaims, and mount storage into Pods.

Day 8 — ConfigMaps + Secrets + RBAC

Create ConfigMaps, Secrets, ServiceAccounts, Roles, and RoleBindings using least privilege.

Day 9 — Troubleshooting + etcd

Practice fixing kubelet, DNS, networking, bad manifests, image pulls, and etcd backups.

Day 10 — Mock CKA Exam

Timed practice using only Bash, kubectl, YAML, and official-style troubleshooting.
