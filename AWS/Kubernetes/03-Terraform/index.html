10 Day Kubernetes Learning Project

Charles Keyes Sr. | Keyes Cloud Solutions

This project documents my 10-day Kubernetes learning lab using Terraform, AWS EC2, Linux, Docker, kubeadm, YAML, networking, storage, troubleshooting, and website deployment.

Current Status: Kubernetes infrastructure deployed with Terraform. DNS is active at kubernetes.keyescloudsolutions.com.

Day 1 — Kubernetes Foundation

Learned the purpose of Kubernetes, nodes, pods, deployments, services, and control plane components.

Day 2 — Build the Cluster

Used Terraform to create AWS EC2 virtual machines for one control-plane node and two worker nodes.

Day 3 — Pods and Deployments

Created Kubernetes pods and deployments. Practiced scaling applications and verifying pod health.

Day 4 — Services and Networking

Exposed workloads using Kubernetes services and learned how traffic reaches applications running inside pods.

Day 5 — YAML Manifests

Built Kubernetes YAML files for pods, deployments, services, labels, selectors, and application configuration.

Day 6 — Ingress and Websites

Studied how DNS, Route 53, services, ingress controllers, and web applications connect together.

Day 7 — Storage

Practiced persistent volumes, persistent volume claims, and storage concepts for applications that need saved data.

Day 8 — ConfigMaps, Secrets, and RBAC

Created ConfigMaps, Secrets, service accounts, roles, and role bindings to understand Kubernetes security basics.

Day 9 — Troubleshooting

Practiced fixing kubelet issues, DNS problems, image pull errors, bad manifests, networking problems, and etcd backup concepts.

Day 10 — Final Project

Goal: Deploy real websites into Kubernetes, including bread.keyescloudsolutions.com, portfolio pages, and Keyes Cloud Solutions demo applications.

Tools Used

AWS, Terraform, EC2, Route 53, Linux, Bash, Docker, containerd, kubeadm, kubectl, YAML, Git, GitHub, VS Code, Obsidian, Kubernetes, and Nginx.

Project Goal

The goal of this lab is to build real cloud engineering experience by creating infrastructure, deploying Kubernetes, troubleshooting systems, and hosting web applications from a working cluster.

Kubernetes Lab Project — Charles Keyes Sr. — Keyes Cloud Solutions
