Key components include:

- AWS Transit Gateway (central routing)
- GCP Network Connectivity Center (hub-and-spoke networking)
- HA VPN with dynamic BGP routing
- Multi-region deployment (Tokyo, São Paulo, Iowa, NY)
- Secure, private infrastructure with no direct backend exposure

This architecture demonstrates real-world enterprise design principles, including scalability, fault tolerance, and secure hybrid connectivity.

---

## 🧠 Architecture Summary

This system connects AWS and GCP using BGP-based HA VPN.

- AWS Transit Gateway acts as the central routing hub across regions
- GCP Network Connectivity Center connects multiple VPCs through a hub-and-spoke model
- Dynamic BGP routing ensures automatic route exchange and failover
- All communication is encrypted and restricted to private networks
