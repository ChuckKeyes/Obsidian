## Anthos

**Definition:**

Anthos is Google's hybrid and multi-cloud application platform that enables organizations to build, deploy, manage, and secure Kubernetes workloads consistently across **Google Cloud, on-premises data centers, AWS, and Azure**.

**PCA Exam Tip:**

If the question says **"manage Kubernetes across multiple clouds," "hybrid cloud,"** or **"consistent platform across environments,"** the answer is **Anthos**.

---
## AWS Lambda

**Definition:**

AWS Lambda is Amazon Web Services' serverless compute service that automatically runs code in response to events without provisioning or managing servers. The Google Cloud equivalent is **Cloud Functions**.

**PCA Exam Tip:**

If the question compares AWS and Google Cloud, remember:

- **AWS Lambda = Google Cloud Functions**

---
## Carrier Peering

**Definition:**

Carrier Peering allows Internet Service Providers (ISPs) to connect customer traffic to Google's public network through a participating carrier. It improves access to **Google public services** but does **not** provide private VPC connectivity.

**PCA Exam Tip:**

If the question says **"ISP," "carrier,"** or **"public Google services,"** the answer is **Carrier Peering**.

---
## Cloud VMware Engine

**Definition:**

Cloud VMware Engine is Google's fully managed VMware platform that runs **vSphere, vSAN, and NSX-T** natively on Google Cloud. It enables organizations to migrate VMware workloads without modifying applications.

**PCA Exam Tip:**

If the question says **"lift-and-shift VMware,"** **"keep VMware tools,"** or **"minimal application changes,"** the answer is **Cloud VMware Engine**.

---
## Cloud VPN

**Definition:**

Cloud VPN creates secure **IPsec VPN tunnels** between Google Cloud VPC networks and on-premises networks or other cloud providers using the public internet.

**PCA Exam Tip:**

If the question says **"encrypted connection over the internet,"** the answer is **Cloud VPN**.

---
## Dedicated Interconnect

**Definition:**

Dedicated Interconnect provides a **private, high-bandwidth physical connection** between an on-premises data center and Google's global network. It offers predictable performance and low latency for enterprise workloads.

**PCA Exam Tip:**

If the question says **"direct fiber connection," "highest bandwidth,"** or **"private enterprise connection,"** the answer is **Dedicated Interconnect**.

---
## Direct Peering

**Definition:**

Direct Peering allows organizations to exchange **public internet traffic** directly with Google's edge network. It improves latency when accessing Google public services but does **not** provide private VPC connectivity.

**PCA Exam Tip:**

If the question says **"public internet peering"** or **"connect directly to Google's public network,"** the answer is **Direct Peering**.

---
## Multi-Cloud

**Definition:**

Multi-cloud is an architecture that uses cloud services from **more than one cloud provider**, such as Google Cloud, AWS, and Azure. Organizations often use multi-cloud to improve resiliency, reduce vendor lock-in, or meet regulatory requirements.

**PCA Exam Tip:**

If the question says **"use workloads across multiple cloud providers,"** the answer is **Multi-cloud**.

---
## OpenStack

**Definition:**

OpenStack is an open-source cloud computing platform used to build and manage private cloud infrastructure. Organizations commonly migrate OpenStack workloads to Google Cloud using migration services such as **Migrate to Virtual Machines**.

**PCA Exam Tip:**

If the question says **"private cloud platform"** or **"migrate OpenStack workloads,"** the answer is **OpenStack**.

---
## Partner Interconnect

**Definition:**

Partner Interconnect provides private connectivity between an on-premises environment and Google Cloud through a **Google-approved connectivity partner**. It is designed for organizations that cannot use Dedicated Interconnect.

**PCA Exam Tip:**

If the question says **"private connection through a service provider,"** the answer is **Partner Interconnect**.

---
## Shared VPC

**Definition:**

Shared VPC enables multiple Google Cloud projects to securely share a single centrally managed VPC network. It simplifies network administration while allowing separate teams to manage their own resources.

**PCA Exam Tip:**

If the question says **"multiple projects sharing one VPC,"** the answer is **Shared VPC**.

---
## VMware vSphere

**Definition:**

VMware vSphere is VMware's enterprise virtualization platform for running and managing virtual machines. Google Cloud VMware Engine provides a managed vSphere environment in Google Cloud.

**PCA Exam Tip:**

If the question says **"existing VMware environment"** or **"vSphere migration,"** think **Cloud VMware Engine**.

---
## Workload Identity Federation

**Definition:**

Workload Identity Federation allows applications running outside Google Cloud—including AWS, Azure, or on-premises—to securely authenticate to Google Cloud services without storing long-lived service account keys.

**PCA Exam Tip:**

If the question says **"AWS workload accessing Google Cloud securely without service account keys,"** the answer is **Workload Identity Federation**.
