
# Vertex AI

**Definition:**

Vertex AI is Google Cloud's unified machine learning platform that enables developers and data scientists to build, train, deploy, monitor, and manage machine learning and generative AI models from a single managed service.

**PCA Exam Tip:**

If the question says **"managed machine learning platform,"** **"build and deploy ML models,"** or **"end-to-end AI workflow,"** think **Vertex AI**.

**Related Services:**

- Vertex AI Agent Builder
- Vertex AI Model Garden
- Vertex AI Pipelines
- Vertex AI Prediction
- Vertex AI Workbench
- Gemini

# Vertex AI Agent Builder

**Definition:**

Vertex AI Agent Builder is a managed Google Cloud service used to build conversational AI agents and virtual assistants that can answer questions, retrieve information, automate business tasks, and integrate with enterprise data sources.

**PCA Exam Tip:**

If the question says **"build an AI assistant,"** **"enterprise chatbot,"** **"conversational AI,"** or **"ground responses using company documents,"** think **Vertex AI Agent Builder**.

**Related Services:**

- Discovery Engine
- Gemini

# Vertex AI Model Garden

**Definition:**

Vertex AI Model Garden provides access to Google's foundation models along with selected open-source and third-party models. It allows developers to discover, evaluate, and deploy pretrained models for generative AI without building models from scratch.

**PCA Exam Tip:**

If the question says **"use a pretrained foundation model,"** **"choose an existing generative AI model,"** or **"deploy Google's foundation models,"** think **Vertex AI Model Garden**.

**Related Services:**

- Gemini
- Vertex AI
- LLM

# Vertex AI Vision

**Definition:**

Vertex AI Vision is a managed Google Cloud service for building computer vision applications that analyze images and video streams using AI. It supports object detection, tracking, classification, and video analytics without requiring extensive machine learning expertise.

# Vertex AI Workbench

**Definition:**

Vertex AI Workbench is a fully managed Jupyter notebook environment for developing, training, testing, and managing machine learning models. It integrates with BigQuery, Vertex AI, and other Google Cloud services to simplify data science workflows.

**PCA Exam Tip:**

If the question says **"managed Jupyter notebooks,"** **"interactive ML development,"** or **"data science environment,"** think **Vertex AI Workbench**.
