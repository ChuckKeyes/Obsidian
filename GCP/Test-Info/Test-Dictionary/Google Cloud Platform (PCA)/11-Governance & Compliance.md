
## BAA — Business Associate Agreement

**Definition:**

A BAA is a legal agreement required under **HIPAA** between a healthcare organization and a service provider that handles protected health information (PHI). It defines each party’s responsibilities for protecting that health information. Google Cloud customers using covered services with PHI must enter into an appropriate BAA with Google.

**PCA Exam Tip:**

If the question mentions **HIPAA**, **PHI**, or a cloud provider handling healthcare data, think **Business Associate Agreement**.

## Organization Policy Service

**Definition:** Enforces organization-wide rules and restrictions across folders and projects. Used to prevent risky configurations, such as creating public IPs or using unsupported regions.

---
## Recommender API

**Definition:** Analyzes Google Cloud resources and recommends improvements for cost, performance, security, reliability, and IAM permissions.

---
# Forseti Security

**Definition:** An open-source security and compliance tool for Google Cloud that scans resources for policy violations. **Note:** Forseti is largely deprecated and has been replaced by Security Command Center for most modern deployments.

---
## Security Command Center (SCC)

**Definition:** Google's centralized security dashboard that detects vulnerabilities, misconfigurations, threats, and compliance findings across cloud resources.

---
## VPC Service Controls

**Definition:** Creates a security perimeter around Google Cloud services to reduce the risk of data exfiltration, even if user credentials are compromised.

---
## Data Catalog Policy Tags

**Definition:** Labels applied to sensitive data (such as PII or financial data) to enforce fine-grained access control in services like BigQuery.

---
## Cloud Data Loss Prevention (DLP)

**Definition:** Discovers, classifies, masks, and protects sensitive information such as Social Security numbers, credit card numbers, and personal information.

---
## CMEK (Customer-Managed Encryption Keys)

**Definition:** Allows customers to control and manage the encryption keys used to protect cloud data through Cloud Key Management Service (Cloud KMS).

---
# Compliance Standards

## PCI DSS (Payment Card Industry Data Security Standard)

**Definition:** A compliance standard requiring organizations that process, store, or transmit credit card information to implement specific security controls.

---
## HIPAA (Health Insurance Portability and Accountability Act)

**Definition:** A U.S. law that requires healthcare organizations to protect the privacy and security of patient health information (PHI).

---
## SOC 2 (System and Organization Controls 2)

**Definition:** An auditing framework that evaluates how organizations protect customer data using security, availability, processing integrity, confidentiality, and privacy controls.

---
## ISO 27001

**Definition:** An international standard for establishing, implementing, maintaining, and continually improving an Information Security Management System (ISMS).
