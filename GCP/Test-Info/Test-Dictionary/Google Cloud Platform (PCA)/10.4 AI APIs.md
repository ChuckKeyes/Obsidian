

# Cloud Natural Language API

**Definition:**

Cloud Natural Language API is a pretrained Google Cloud AI service that analyzes text to identify **sentiment, entities, syntax, and content classification** without requiring model training.

**PCA Exam Tip:**

If the question says **"analyze text,"** **"sentiment analysis,"** **"entity recognition,"** or **"classify documents,"** think **Cloud Natural Language API**.

**Related Services:**

- Vertex AI
- Gemini
- Machine Learning

---

# Dialogflow CX

**Definition:**

Dialogflow CX (Customer Experience) is Google's enterprise conversational AI platform used to build **complex virtual agents and chatbots** with advanced conversation flows, state management, and multi-turn interactions.

**PCA Exam Tip:**

If the question says **"enterprise chatbot,"** **"complex conversation flow,"** **"customer service automation,"** or **"large conversational application,"** think **Dialogflow CX**.

**Related Services:**

- Dialogflow ES
- Vertex AI Agent Builder
- Gemini

---

# Dialogflow ES

**Definition:**

Dialogflow ES (Essentials) is Google's conversational AI platform for building **simple chatbots and virtual assistants** using natural language understanding. It is designed for less complex conversational applications than Dialogflow CX.

**PCA Exam Tip:**

If the question says **"simple chatbot,"** **"virtual assistant,"** or **"basic conversational AI,"** think **Dialogflow ES**.

**Related Services:**

- Dialogflow CX
- Vertex AI Agent Builder

---

# Document AI

**Definition:**

Document AI is a managed Google Cloud service that uses machine learning to extract structured information from documents such as invoices, receipts, contracts, tax forms, identity documents, and other business forms.

**PCA Exam Tip:**

If the question says **"extract data from invoices,"** **"process forms,"** **"OCR with structured output,"** or **"analyze business documents,"** think **Document AI**.

**Related Services:**

- Vertex AI
- Cloud Storage
- BigQuery
- Vision API

---

# Vision API

**Definition:**

Vision API is a pretrained Google Cloud AI service that analyzes images to detect **objects, faces, logos, landmarks, labels, text (OCR), and explicit content** without requiring custom model training.

**PCA Exam Tip:**

If the question says **"analyze images,"** **"OCR,"** **"detect objects,"** **"identify logos,"** or **"image classification without training a model,"** think **Vision API**.

**Related Services:**

- Document AI
- Vertex AI Vision
- Vertex AI
