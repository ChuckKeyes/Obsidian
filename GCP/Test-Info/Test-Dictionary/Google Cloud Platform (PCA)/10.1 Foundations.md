# Explainable AI

**Definition:**

Explainable AI is a Google Cloud capability that helps users understand **why a machine learning model made a prediction** by identifying the features and data that most influenced the model's decision. This improves transparency, trust, and regulatory compliance.

**PCA Exam Tip:**

If the question says **"understand model predictions,"** **"interpret AI decisions,"** or **"identify feature importance,"** think **Explainable AI**.

**Related Services:**

- Vertex AI
- Vertex AI Prediction
- Machine Learning
- MLOps

# Large Language Model (LLM)

**Definition:**

A Large Language Model (LLM) is an AI model trained on massive amounts of text and other data to understand and generate natural language. LLMs can answer questions, summarize documents, generate code, translate languages, and create conversational experiences.

**PCA Exam Tip:**

If the question says **"generative AI,"** **"chatbot,"** **"text generation,"** or **"foundation model,"** think **LLM**.

**Related Services:**

- Gemini
- Vertex AI
- Vertex AI Model Garden
- Vertex AI Agent Builder
- RAG

# Retrieval-Augmented Generation (RAG)

**Definition:**

Retrieval-Augmented Generation (RAG) is an AI architecture that combines a Large Language Model (LLM) with an external knowledge source. Before generating a response, the model retrieves relevant information from documents, databases, or search indexes, improving accuracy and reducing hallucinations.

**PCA Exam Tip:**

If the question says **"use company documents with an LLM,"** **"ground AI responses in enterprise data,"** or **"retrieve information before generating an answer,"** think **RAG**.

**Related Services:**

- Vertex AI Agent Builder
- Discovery Engine
- Gemini
- LLM
