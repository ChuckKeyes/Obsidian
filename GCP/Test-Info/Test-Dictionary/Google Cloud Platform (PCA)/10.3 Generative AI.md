
# Discovery Engine

**Definition:**

Discovery Engine is a fully managed Google Cloud service that provides AI-powered search, recommendations, and conversational experiences for websites, retail catalogs, enterprise knowledge bases, and document collections. It enables semantic search and natural language interactions without managing search infrastructure.

**PCA Exam Tip:**

If the question says **"conversational commerce,"** **"product catalog search,"** **"AI-powered recommendations,"** **"enterprise search,"** or **"semantic search,"** think **Discovery Engine**.

**Related Services:**

- Vertex AI Agent Builder
- Gemini
- RAG
- Vertex AI

# Gemini

**Definition:**

Gemini is Google's family of multimodal foundation models that can understand and generate text, images, code, and other content. Gemini powers generative AI applications such as chat, summarization, reasoning, code generation, and content creation through Vertex AI.

**PCA Exam Tip:**

If the question says **"generate text,"** **"summarize documents,"** **"reason over data,"** **"foundation model,"** or **"multimodal AI,"** think **Gemini**.

**Related Services:**

- Vertex AI
- Vertex AI Model Garden
- Vertex AI Agent Builder
- Gemini Code Assist
- LLM

---

# Gemini Code Assist

**Definition:**

Gemini Code Assist is Google's AI-powered coding assistant that helps developers generate, explain, review, debug, and optimize code directly within supported integrated development environments (IDEs) and Google Cloud tools.

**PCA Exam Tip:**

If the question says **"AI coding assistant,"** **"generate code,"** **"explain source code,"** or **"developer productivity,"** think **Gemini Code Assist**.

**Related Services:**

- Gemini
- Vertex AI
- Cloud Workstations

# NotebookLM

**Definition:**

NotebookLM is Google's AI-powered research assistant that uses your own uploaded documents as the knowledge source to generate summaries, answer questions, explain concepts, and organize information. It helps users interact with their documents using natural language.

**PCA Exam Tip:**

If the question says **"AI assistant using uploaded documents,"** **"summarize personal documents,"** or **"research assistant,"** think **NotebookLM**.

**Related Services:**

- Gemini
- RAG
- Vertex AI
