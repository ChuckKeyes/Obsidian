# BigQuery ML

**Definition:**

BigQuery ML is a Google Cloud service that allows you to **create, train, evaluate, and use machine learning models directly in BigQuery using SQL**, without moving data to another machine learning platform.

**PCA Exam Tip:**

If the question says **"build machine learning models using SQL,"** **"keep the data in BigQuery,"** or **"predict from structured data without exporting it,"** think **BigQuery ML**.

**Related Services:**

- BigQuery
- Vertex AI
- Machine Learning
- Looker Studio

---

# Embeddings

**Definition:**

Embeddings are numerical vector representations of text, images, or other data that capture their semantic meaning. Similar pieces of information are stored as vectors that are close together, enabling semantic search, recommendations, Retrieval-Augmented Generation (RAG), and vector search.

**PCA Exam Tip:**

If the question says **"semantic search,"** **"vector search,"** **"similarity search,"** or **"retrieve relevant documents before generating an AI response,"** think **Embeddings**.

**Related Services:**

- Discovery Engine
- Gemini
- RAG
- Vertex AI

---

# ETL (Extract, Transform, Load)

**Definition:**

ETL is a data integration process that:

1. **Extracts** data from one or more source systems.
2. **Transforms** or cleans the data into the required format.
3. **Loads** the processed data into a destination such as a data warehouse, database, or data lake.

Google Cloud commonly uses **Dataflow**, **Cloud Data Fusion**, and **BigQuery** as part of ETL workflows.

**PCA Exam Tip:**

If the question says **"clean or transform data before loading into BigQuery,"** **"data integration,"** or **"prepare data for analytics,"** think **ETL**.

**Related Services:**

- BigQuery
- Dataflow
- Cloud Data Fusion
- Cloud Storage

---

# Looker Studio

**Definition:**

Looker Studio is Google's business intelligence (BI) and data visualization service that creates **interactive dashboards, charts, and reports** using data from BigQuery, Cloud SQL, Google Sheets, and many other data sources.

**PCA Exam Tip:**

If the question says **"interactive dashboards,"** **"business reports,"** **"visualize analytics,"** or **"executive reporting,"** think **Looker Studio**.

**Related Services:**

- BigQuery
- BigQuery ML
- Looker
- ETL

|---|---|
