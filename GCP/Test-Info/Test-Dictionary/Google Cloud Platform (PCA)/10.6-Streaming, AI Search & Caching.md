
## Autoclass (Cloud Storage)

**Definition:**

**Autoclass** automatically moves Cloud Storage objects between storage classes (Standard, Nearline, Coldline, Archive) based on how frequently the objects are accessed.

Unlike Object Lifecycle Management, you do **not** create rules. Google Cloud automatically optimizes storage costs.

**PCA Exam Tip:**

If the question says:

- "reduce storage cost automatically"
- "unknown access patterns"
- "no lifecycle rules"

the answer is usually **Autoclass**.

## Cloud Monitoring Alerting Policies

**Definition:**

Alerting Policies define **when Cloud Monitoring sends notifications**.

Alerts can be triggered by:

- CPU
- Memory
- Disk
- Custom metrics
- Log-based metrics
- Uptime checks

Notifications can be sent through:

- Email
- SMS
- Slack
- PagerDuty
- Webhooks
- Pub/Sub

**PCA Exam Tip:**

Monitoring collects metrics.

Alerting Policies notify people.

# Document AI

Definition

Document AI is a managed Google Cloud service that extracts structured information from documents such as invoices, receipts, contracts, forms, and identity documents using machine learning.

PCA Exam Tip

If the question says:

- process invoices
- extract fields from forms
- analyze contracts
- OCR plus structured extraction

think **Document AI**, not Vision API.

## Vertex AI Agent Builder

**Definition:**

Vertex AI Agent Builder creates **AI assistants and conversational agents** using Google's Gemini models.

It can search enterprise data and answer user questions using Retrieval-Augmented Generation (RAG).

Supports:

- Websites
- PDFs
- BigQuery
- Cloud Storage
- Databases
- APIs

**PCA Exam Tip:**

If the question asks for a chatbot that searches company documents using Gemini, think **Vertex AI Agent Builder**.

---
## Discovery Engine

**Definition:**

Discovery Engine powers **enterprise search** across structured and unstructured data.

Users ask questions in natural language.

Discovery Engine retrieves relevant information and can provide it to Vertex AI Agent Builder for responses.

**Common data sources**

- Cloud Storage
- Websites
- PDFs
- BigQuery
- Databases

**PCA Exam Tip:**

Search = Discovery Engine

Conversation = Agent Builder

## Pub/Sub + Dataflow

**Definition:**

Pub/Sub receives streaming events.

Dataflow processes those events in real time.

Example:

```
IoT Sensors

↓

Pub/Sub

↓

Dataflow

↓

BigQuery

↓

Looker Studio
```

**PCA Exam Tip:**

Pub/Sub = messaging.

Dataflow = processing.

BigQuery = analytics.

## Structured Schema Constraints

**Definition:**

Schema constraints define what data is allowed before it is stored or processed.

Examples include:

- Required fields
- Data types
- Maximum length
- Allowed values
- Numeric ranges
- Validation rules

This ensures applications receive valid, consistent data.

**PCA Exam Tip:**

If the requirement is to **validate incoming structured data** before downstream processing, look for schema validation or schema enforcement rather than custom application code.

## Redis (Memorystore for Redis)

**Definition:**

Redis is an **in-memory key-value database** used for ultra-fast data access.

Google Cloud provides it as **Memorystore for Redis**.

Common uses:

- Caching
- Session storage
- Leaderboards
- Queues
- Rate limiting

**PCA Exam Tip:**

If the application repeatedly reads the same data and needs **millisecond or sub-millisecond latency**, the answer is often **Memorystore for Redis** rather than Cloud SQL or Firestore.
