## Backup and DR

**Definition:**

Backup and DR is Google Cloud's fully managed backup and disaster recovery service that provides centralized protection for virtual machines, databases, file systems, and enterprise applications. It supports scheduled backups, replication, and rapid recovery across hybrid and multi-cloud environments.

**PCA Exam Tip:**

If the question says **"centralized backup," "enterprise disaster recovery,"** or **"recover workloads after a failure,"** the answer is **Backup and DR**.

---
## Cloud VMware Engine

**Definition:**

Cloud VMware Engine is a fully managed VMware environment that allows organizations to run **VMware vSphere, vSAN, and NSX-T** natively on Google Cloud without modifying existing VMware applications.

**PCA Exam Tip:**

If the question says **"lift-and-shift VMware workloads"** or **"move VMware to Google Cloud without refactoring,"** the answer is **Cloud VMware Engine**.

---
## Database Migration Service (DMS)

**Definition:**

Database Migration Service (DMS) is a fully managed service that migrates MySQL, PostgreSQL, and SQL Server databases into Google Cloud with minimal downtime.

**PCA Exam Tip:**

If the question says **"migrate an on-premises database with minimal downtime,"** the answer is **Database Migration Service (DMS)**.

---
## Migrate to Containers

**Definition:**

Migrate to Containers modernizes existing virtual machine applications by converting them into containers that can run on **Google Kubernetes Engine (GKE)** or **Cloud Run**.

**PCA Exam Tip:**

If the question says **"convert VMs into containers,"** the answer is **Migrate to Containers**.

---
## Migrate to Virtual Machines

**Definition:**

Migrate to Virtual Machines migrates virtual machines from VMware, AWS, Azure, and physical environments into Google Compute Engine while minimizing downtime.

**PCA Exam Tip:**

If the question says **"migrate VMs from another cloud or VMware into Compute Engine,"** the answer is **Migrate to Virtual Machines**.

---
## Migration Center

**Definition:**

Migration Center is Google's centralized assessment and planning service that inventories existing infrastructure, analyzes workloads, estimates costs, and recommends migration strategies before moving workloads to Google Cloud.

**PCA Exam Tip:**

If the question says **"inventory servers," "assess migration readiness,"** or **"plan a cloud migration,"** the answer is **Migration Center**.

---
## Migrate for GKE _(Legacy)_

**Definition:**

Migrate for GKE was Google's migration service for converting existing virtual machines into containers running on Google Kubernetes Engine. It has been replaced by **Migrate to Containers**.

**PCA Exam Tip:**

If the question mentions **"legacy VM-to-GKE migration,"** the answer is **Migrate for GKE**. For modern deployments, choose **Migrate to Containers**.

---
## Storage Transfer Service

**Definition:**

Storage Transfer Service securely transfers large amounts of data between on-premises storage, Amazon S3, Azure Blob Storage, HTTP sources, and Google Cloud Storage. Transfers can be scheduled or automated.

**PCA Exam Tip:**

If the question says **"copy data from S3 to Cloud Storage"** or **"scheduled cloud storage migration,"** the answer is **Storage Transfer Service**.

---
## Transfer Appliance

**Definition:**

Transfer Appliance is a secure physical storage device provided by Google for transferring **hundreds of terabytes or petabytes** of on-premises data into Google Cloud when network bandwidth is insufficient.

**PCA Exam Tip:**

If the question says **"ship a storage device," "massive offline migration,"** or **"internet connection is too slow,"** the answer is **Transfer Appliance**.

---
## Velostrata _(Historical)_

**Definition:**

Velostrata was the migration technology acquired by Google that became the foundation for **Migrate to Virtual Machines**. It enabled rapid streaming of virtual machine workloads into Google Cloud before full migration.

**PCA Exam Tip:**

Older documentation may reference **Velostrata**, but for current Google Cloud exams, know **Migrate to Virtual Machines** instead.
