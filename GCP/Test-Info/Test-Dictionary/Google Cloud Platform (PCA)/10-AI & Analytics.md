

## ETL — Extract, Transform, Load

**Definition:**

ETL is a data-processing method that:

1. Extracts data from source systems.
2. Transforms or cleans the data.
3. Loads the finished data into a database, warehouse, or data lake.

**PCA Exam Tip:**

If the question says **clean or transform data before loading it into BigQuery**, think **ETL**. Google Cloud often uses Dataflow or Cloud Data Fusion for these workflows.
