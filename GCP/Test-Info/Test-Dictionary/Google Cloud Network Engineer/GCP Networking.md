
  # Cloud CDN.md

**← [[Google Cloud]]**  
**← [[00-Dictionary Index]]**

## Cloud CDN

**Definition:**

Cloud CDN is Google's global Content Delivery Network (CDN) that caches static and dynamic web content at edge locations around the world. It reduces latency, improves application performance, and lowers the load on backend services.

**PCA Exam Tip:**

If the question says **"cache content globally," "reduce latency,"** or **"improve website performance,"** the answer is **Cloud CDN**.

**Official Documentation:**

[https://cloud.google.com/cdn/docs](https://cloud.google.com/cdn/docs)

## Cloud Router

**Definition:**

Cloud Router dynamically exchanges routes between Google Cloud VPC networks and on-premises networks using Border Gateway Protocol (BGP). It is commonly used with Cloud VPN and Cloud Interconnect.

**PCA Exam Tip:**

If the question says **"dynamic routing," "BGP,"** or **"hybrid connectivity,"** the answer is **Cloud Router**.

**← [[Google Cloud]]**  
**← [[00-Dictionary Index]]**

## VPC Network Peering

**Definition:**

VPC Network Peering privately connects two VPC networks over Google's backbone network, allowing communication using internal IP addresses. **Peered VPCs must not have overlapping subnet IP ranges.**

**PCA Exam Tip:**

If the question says **"connect two VPCs privately"** and **"non-overlapping IP ranges,"** the answer is **VPC Network Peering**.

**Official Documentation:**

[https://cloud.google.com/vpc/docs/vpc-peering](https://cloud.google.com/vpc/docs/vpc-peering)
