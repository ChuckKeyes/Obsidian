🔍 How to find & remove stray .git folders:

You can list them:


find . -name ".git" -type d


Delete ALL except the root one:

find . -name ".git" -type d -exec rm -rf {} +


################################################################################

✅ Windows (Git Bash / WSL / Linux Command Line)

Run this inside the root of your Obsidian vault:

find . -type d -name ".terraform" -prune -exec rm -rf {} +


✔ Deletes every .terraform directory
✔ Leaves all .tf files untouched
✔ Safe for Templates, Notes, Projects
